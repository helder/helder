# 3D

3D is markup: a `<Scene>` from `helder/scene/view` in a view, the scene's
own tags inside it. Never a renderer, a custom material, GPU code or a
script of your own unless the user asks for one by name: the studio keeps
a screen's frames as data, and a markup scene is data (crisp, cheap);
anything else only pixels.

```tsx file=toy.tsx
import { signal } from "helder/view";
import { Clock } from "helder/ui";
import { Scene } from "helder/scene/view";
import { vec3, vec4 } from "helder/gfx";
import { Quat } from "helder/math";

// the model (radians): a scenario's boot sets it, the clock turns it
export const spin = signal(0.6);

export function Toy() {
	let last = -1;
	Clock.add(t => {
		spin(spin() + (last < 0 ? 0 : Math.min(0.05, t - last)) * 1.2);
		last = t;
		return true;
	});
	return <view flexGrow={1} background="#0f172a">
		<Scene flexGrow={1}>
			<camera position={vec3(0, 2.2, 6)} rotation={Quat.fromEuler(-0.35, 0, 0)} fov={0.8}/>
			<directionalLight intensity={1.6} rotation={Quat.fromEuler(-0.9, 0.6, 0)}/>
			<pointLight position={vec3(-2, 1.5, 2)} intensity={4} range={10}/>
			<mesh rotation={Quat.fromEuler(0.5, spin(), 0)}>
				<boxGeometry width={1.2} height={1.2} depth={1.2}/>
				<standardMaterial color={vec4(0.36, 0.55, 0.98, 1)} roughness={0.35}/>
			</mesh>
			<mesh position={vec3(-2.2, 0, 0)}>
				<sphereGeometry radius={0.6}/>
				<standardMaterial color={vec4(0.95, 0.55, 0.36, 1)} roughness={0.5}/>
			</mesh>
			<mesh position={vec3(2.2, 0, 0)} rotation={Quat.fromEuler(spin(), 0, 0)}>
				<torusGeometry radius={0.55} tube={0.2}/>
				<standardMaterial color={vec4(0.5, 0.85, 0.6, 1)} metallic={0.3} roughness={0.3}/>
			</mesh>
		</Scene>
	</view>;
}
```

```tsx file=toy.scenario.tsx
import { scenario } from "helder/scenario";
import { spin } from "./toy";

export const still = scenario({ name: "Toy/Still" });
export const turned = scenario({ name: "Toy/Turned", boot() { spin(2); } });
export const spinning = scenario({ name: "Toy/Spinning", loop: 2 });
```

(`main.tsx` shows `<Toy/>` in its window, as in the start topic.)

- A 3D game's model lives in exported signals (a level, the player's
  place): scenarios set its moments, the app's clock runs it, as in the
  game topic.
- Tags: `node` (a group: `position`, `rotation`, `scale` on any tag),
  `mesh` with a geometry tag (`boxGeometry`, `sphereGeometry`,
  `cylinderGeometry`, `coneGeometry`, `capsuleGeometry`, `torusGeometry`,
  `planeGeometry`...) and a material tag (`standardMaterial`,
  `lambertMaterial`, `toonMaterial`, `unlitMaterial`...), the lights
  (`directionalLight`, `pointLight`, `spotLight`, `hemisphereLight`),
  `camera` (`fov`), `lines`, `text3d`; `<Effects bloom={0.6}>` for the
  look; `onClick` on a mesh to pick it.
- Values are `helder/gfx`'s: `vec3`, `vec4` (colours: r, g, b, a from 0 to
  1), `Quat.fromEuler(x, y, z)` (radians).
