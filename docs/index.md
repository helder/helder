# Docs

Helder is an open-source stack for apps and games. You write TypeScript (or Haxe), and it compiles to native apps for Windows, macOS, Linux, Android and iOS, and to WebAssembly for the web.

Everything here is an early preview. APIs, commands and settings can change without notice.

## Other places

- The source is on [GitHub](https://github.com/helder/helder). The TypeScript examples are the folders named `examples/ts-*`.
- [Examples](https://helder.build/examples/) plays helder's examples in your browser.
- [Explore](https://helder.build/explore) lists apps and games published on helder.run.
- [Agents](https://helder.build/agents) is for working on a Helder app with a coding agent.
