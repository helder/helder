# 2D: canvas and images

`helder.canvas` draws paths, gradients, strokes, images and text, on the GPU into a window or on the CPU into pixels, with the same result on every machine. From TypeScript it speaks the browser's Canvas 2D, so drawing code you already have runs natively.

<Image src="canvas.webp" alt="A turning star with a glow over a violet gradient sky, inside dashed elliptical orbits" caption="examples/canvas-window: a gradient, dashed orbits, a clip and a layer, drawn on the GPU."/>

```ts
import { Canvas } from "helder/canvas";

const canvas = new Canvas(200, 100);
const ctx = canvas.getContext("2d");
const sky = ctx.createLinearGradient(0, 0, 200, 0);
sky.addColorStop(0, "#e11d48");
sky.addColorStop(1, "#2563eb");
ctx.fillStyle = sky;
ctx.beginPath();
ctx.roundRect(10, 10, 180, 80, 12);
ctx.fill();
canvas.saveAs("card.png");
```

```haxe
import helder.canvas.*;
import helder.canvas.Stroke;

var c = new Canvas(200, 100);
var p = new Path();
p.roundRect(10, 10, 180, 80, 12);
var sky = new LinearGradient(0, 0, 200, 0);
sky.addStop(0, 0xFFE11D48).addStop(1, 0xFF2563EB);
c.fill(p, Paint.shaded(sky));
var s = new Stroke(4);
s.dash = new Dash([8, 4]);
c.stroke(p, s, Paint.solid(0xFF111827));
sys.io.File.saveBytes("card.png", c.toPng());
```

## What else

- **Paths and paints:** curves, arcs, SVG path data, linear, radial and conic gradients, patterns, every blend mode, clips, masks and layers.
- **Back ends:** the CPU (exact, testable pixels), the GPU in a window or inside a UI, and the browser's own canvas on the web.
- **Images:** PNG, JPEG, GIF and WebP decoded in helder's own code, animated GIFs and WebPs, decoding on other threads.
- **Sprites:** batched textured quads from TexturePacker atlases, thousands in one draw ([Bunnymark](https://helder.build/examples/#bunnymark)).
- **PDF:** pages rendered to pixels by `helder.pdf`.
