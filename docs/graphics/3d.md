# 3D scenes

`helder.scene` is a 3D engine you can read: a scene graph of nodes, physically based materials, lights and shadows, post effects and particles, all on helder's GPU layer. Use it as a whole game's renderer, or put a `<Scene>` inside a UI beside your panels and buttons.

<Example id="scene-nodes"/>

A world is a tree of nodes. A node's position, rotation and scale are relative to its parent, so turning a pivot turns everything under it. What a node draws, lights or sees is attached to it.

```ts
const world = new World("system");
const sun = world.node("sun");
// base colour, metallic, roughness, emission
const glow = new Material("sun", vec4(1, 0.8, 0.4, 1), 0, 1, vec3(2, 1.4, 0.5));
MeshRenderer.attach(sun, Shapes.sphere(device, glow, 0.6));
Light.attach(sun, Light.pointLight(vec3(1, 0.85, 0.6), 30, 20));

const orbit = world.node("orbit", sun);      // a pivot: turns, draws nothing
const planet = world.node("planet", orbit);
planet.position = vec3(2.6, 0, 0);

const eye = world.node("eye");
const camera = Camera.attach(eye, Camera.perspective(0.8, 0.1, 100));
eye.lookAt(vec3(0, 0, 0));
renderer.draw(enc, world, camera);
```

```haxe
var world = new World("system");
var sun = world.node("sun");
// base colour, metallic, roughness, emission
var glow = new Material("sun", new Vec4(1, 0.8, 0.4, 1), 0, 1,
  new Vec3(2, 1.4, 0.5));
MeshRenderer.attach(sun, Shapes.sphere(device, glow, 0.6));
Light.attach(sun, Light.pointLight(new Vec3(1, 0.85, 0.6), 30, 20));

var orbit = world.node("orbit", sun);      // a pivot: turns, draws nothing
var planet = world.node("planet", orbit);
planet.position = new Vec3(2.6, 0, 0);

var eye = world.node("eye");
var camera = Camera.attach(eye, Camera.perspective(0.8, 0.1, 100));
eye.lookAt(new Vec3(0, 0, 0));
renderer.draw(enc, world, camera);
```

In a UI, the same scene is markup, and signals move its nodes without re-rendering anything:

```haxe
<Scene grow={1} camera={camera}>
  <node name="lamp" position={pos}>
    <mesh shape="sphere" size={0.4} color={gold} onClick={() -> lit(on -> !on)}/>
    <Show when={lit}><light kind="point" intensity={6.0} range={8.0}/></Show>
  </node>
</Scene>
```

## In this section

- [Models and materials](3d/models.md): glTF files typed when you build, animation, the standard material and your own.
- [Lights and shadows](3d/lights.md): the sun, point and spot lights, hundreds of lights, soft shadows, sky and environment light.
- [Effects and post](3d/effects.md): HDR, bloom, tone mapping, ambient occlusion, depth of field, reflections, fog.
- [Particles and instancing](3d/particles.md): a million GPU particles, instanced meshes and levels of detail.

## What else

- **Picking:** rays cast at triangles, and `onClick` on any mesh in a `<Scene>`.
- **Lines and text:** lines with a width and dashes, and text extruded into the world.
- **Debugging:** immediate debug lines from anywhere, helpers, a frame-time overlay.
- **A fixed step:** the simulation at a steady rate, whatever the display's.
