# helder.scene

A scene layer for 3D games on `helder.gfx`, in pure Haxe (Haxe package
`helder.scene`; what comes next: the [roadmap](/README.md)). It is ordinary
gfx code: use the parts you want, replace the rest.

These pages go from the scene graph to what draws it:

- [World and nodes](world.md): the scene graph, cameras, the fixed step;
- [glTF and models](models.md): files typed when compiling, packed for
  run time, animated;
- [Materials](materials.md), [Lights and shadows](lights.md), [Fog](fog.md),
  [HDR and post-processing](post.md) and [Post effects](effects.md) (AO,
  depth of field, outlines, FXAA, a LUT): the renderer;
- [Instancing](instancing.md) and [GPU particles](particles.md): many
  things in few draws;
- [Lines](lines.md), [Text in the world](text.md) and
  [Picking](picking.md): lines with a width, text as geometry, rays cast
  at triangles;
- [`<Scene>` markup](markup.md): the scene in helder.view's markup, inside a
  ui;
- [Input](input.md), [Debugging](debugging.md) and
  [TypeScript](typescript.md).

On the docs site each page's examples run in the page (WebAssembly, on
WebGPU or WebGL2): press Play. Their source is the file shown beside
them, built and tested with the rest of the repository; `helder run
<file>` runs one natively.

## Math

gfx's shader types (`Vec2`, `Vec3`, `Vec4`, `Mat4` of `helder.gfx.shader`)
are the CPU's types too, so what the CPU computes is what a shader reads.
3d adds, as immutable values like them:

- `Quat`: a unit quaternion (`axisAngle`, `fromEuler`, `fromMat4`, `*`,
  `rotate`, `toMat4`, `slerp`, `conjugate`);
- `Aabb`: an axis-aligned box (`union`, `transform`, `contains`,
  `intersects`, `ray`);
- `MathTools`, a static extension of `Mat4` (`using
  helder.scene.math.MathTools`): `inverse`, `transpose`, `determinant`,
  `compose(t, r, s)`, `decompose`, `lookAt`, `lookRotation`,
  `transformPoint`, `transformDir`, `normalMatrix`.

## Tests

`tests/3d/SceneTest.hx`, `tests/3d/GltfTest.hx`, the `*.test.hx` beside
the sources (Geometry, Curve3, Sprites, the shading models, Material,
InstancedMesh, Bvh, Raycaster, DebugDraw, Extrude: `helder test`,
natively and as wasm32-wasi) and the frames
of `tests/3d/Scenes.hx` against `tests/3d/<scene>.png` (`bun run test 3d`,
natively, and some from TypeScript too: tests/3d/ts; `bun run test
3d-web`, WebGPU and WebGL2 in Chromium). The
examples on these pages are built by the examples lane (`bun run test
examples`).

`examples/gltf-viewer/sample.glb` (and `tests/3d/skinned.glb`,
`tests/3d/textured.glb`, `examples/showroom/normals.glb`) is generated by
`tests/3d/SampleModel.hx` (MIT).
